Installation Guide

Choose your platform and follow the steps to get started.

1

Install the library

ATOMiK requires Python 3.9 or later. Install from source:

Copy Terminal git clone https://github.com/MatthewHRockwell/ATOMiK.git cd ATOMiK/software/atomik_core pip install -e .
2

Verify the installation

Run a quick test to confirm everything works:

Copy Python from atomik_core import AtomikContext ctx = AtomikContext() ctx.load(0xDEADBEEF) ctx.accum(0x000000FF) assert ctx.read() == 0xDEADBE10 print("ATOMiK is working!")
3

Run the test suite

Validate all 353 tests pass on your system:

Copy Terminal cd ATOMiK/software/atomik_core python -m pytest tests/ -v
Expected: 353 tests passed, covering all algebraic properties, edge cases, and integration scenarios.
1

Download the header

ATOMiK for C is a single header file. No dependencies, no build system required.

Copy Terminal git clone https://github.com/MatthewHRockwell/ATOMiK.git # The header is at: # ATOMiK/software/atomik_core_c/atomik_core.h
i Copy atomik_core.h into your project's include directory. That's all you need.
2

Include and use

Include the header and start using the 4-operation API:

Copy C #include "atomik_core.h" int main() { struct atomik_table *t = atomik_table_create(1024); atomik_load(t, 0, 0xDEADBEEF); atomik_accum(t, 0, 0x000000FF); uint64_t state = atomik_read(t, 0); // state == 0xDEADBE10 atomik_table_destroy(t); return 0; }
3

Compile

Compile with any C99-compatible compiler:

Copy Terminal gcc -O2 -o myapp myapp.c # Or with C++: g++ -O2 -std=c++17 -o myapp myapp.cpp
Performance: The C library achieves ~500M ops/sec on modern x86 hardware. Zero dependencies, zero allocations after init.
i The kernel module requires a Professional or Enterprise subscription. It includes a 90-day free trial with full functionality. Start your trial
1

Prerequisites

Ensure you have kernel headers and build tools installed. The installer will verify these for you, but installing them ahead of time saves a step:

Copy Terminal # Ubuntu / Debian sudo apt update sudo apt install build-essential linux-headers-$(uname -r) dkms # Fedora / RHEL sudo dnf install kernel-devel kernel-headers gcc make dkms
i Requires Linux kernel 5.15 or later, x86_64 architecture. The module auto-detects ATOMiK hardware (FPGA/ASIC) when present and falls back to software acceleration on standard systems.
2

Download and install

Clone the repository and run the automated installer:

Copy Terminal git clone https://github.com/MatthewHRockwell/ATOMiK.git cd ATOMiK/software/atomik_kmod sudo ./install.sh

Or install with a license key:

Copy Terminal sudo ./install.sh --license ATOMIK-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX

The installer runs pre-flight checks, then:

✓ Builds the kernel module and 4 userspace tools, sets up DKMS for automatic kernel upgrades, creates the atomik system group, installs the systemd service, and loads the module immediately.
3

Verify the installation

Check that the module is loaded and running:

Copy Terminal # Check module status atomik-status # Expected output: # ATOMiK v0.2.0 — Delta-State Accelerator # Backend: software # License: trial (90 days remaining) # Status: ACTIVE
4

Run the test suite

Validate everything works on your system:

Copy Terminal # Quick smoke test (18 tests) atomik-test # Full suite: functional, security, licensing, stability (34 tests) sudo atomik-full-test
Expected: 34/34 tests pass covering functional correctness, security, licensing, stability, and privacy.
5

Benchmark your system

Run the performance benchmark to see ATOMiK in action:

Copy Terminal # Runs change detection, accumulation, and batch benchmarks # with CPU temperature and frequency monitoring sudo atomik-bench
Typical results: Batch mode achieves 50-70x speedup over individual operations. ATOMiK fingerprinting matches or beats memcmp for change detection.
6

Add your license key (optional)

After purchasing, add your license key to persist across reboots:

Copy Terminal # Add your license key echo 'options atomik license_key=ATOMIK-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX' | \ sudo tee /etc/modprobe.d/atomik.conf sudo chmod 600 /etc/modprobe.d/atomik.conf # Reload the module sudo systemctl restart atomik atomik-status
7

Uninstall (if needed)

Clean removal with one command:

Copy Terminal sudo atomik-uninstall # Keep trial state sudo atomik-uninstall --purge # Remove everything
