NOTES (honest framing — see feedback_perf_matrix_framing):
- The architectural result is OPS REDUCTION in the profile path: hw ops drop 64->4, 256->16,
  1024->32 (≈16x at the 8-reg/64-op case). Fewer hardware ops = less memory traffic, the
  real benefit on bandwidth-constrained systems.
- STATE 8/64 profile is ALSO faster in raw cycles here: 7221 vs 9170 software (~1.27x).
- The direct/batched columns show cycle OVERHEAD vs software on this soft-CPU — adapter MMIO
  is expensive at ~100 MHz. Do NOT frame the matrix as cycle "wins/losses"; the win is the
  ops/traffic reduction, which compounds on real bandwidth-bound workloads.
- AGENT-profile cells with ~24M cycles are timing outliers from the relevance-recency
  (anim_now_ms) path, not representative — treat as anomalous.
