## 1. SPI Protocol Overview

### Signal Roles

| Signal | Direction (Master) | Description |
|--------|-------------------|-------------|
| SCLK   | Output            | Serial clock, generated by master |
| MOSI   | Output            | Master Out Slave In (data to slave) |
| MISO   | Input             | Master In Slave Out (data from slave) |
| SS/CS  | Output            | Slave Select (active-low, directly per slave) |

### SPI Modes (CPOL / CPHA)

| Mode | CPOL | CPHA | Clock Idle | Data Sampled | Data Shifted |
|------|------|------|------------|--------------|--------------|
| 0    | 0    | 0    | Low        | Rising edge  | Falling edge |
| 1    | 0    | 1    | Low        | Falling edge | Rising edge  |
| 2    | 1    | 0    | High       | Falling edge | Rising edge  |
| 3    | 1    | 1    | High       | Rising edge  | Falling edge |

**Mode 0** is the most common default. The boot flash (P25Q32U), SD cards in SPI mode, and the MAX3421E all use Mode 0.

### Clock Speed Considerations

The PicoRV32 bus clock is 25.2 MHz. SPI peripheral clocks are derived from this:

| Divider | SPI Clock | Use Case |
|---------|-----------|----------|
| /2      | 12.6 MHz  | Maximum for short traces (<5 cm) |
| /4      | 6.3 MHz   | SD card high-speed, MAX3421E max (26 MHz limit, but conservative) |
| /8      | 3.15 MHz  | Safe default for breadboard wiring |
| /16     | 1.575 MHz | SD card initialization (must be <400 kHz initially, ramp up after) |
| /64     | 394 kHz   | SD card init phase (<400 kHz required) |

### Data Framing

- **Standard SPI**: 8-bit frames, MSB first
- **Boot Flash**: 8-bit command + 24-bit address + N data bytes
- **SD Card**: 48-bit commands (6 bytes), MSB first
- **MAX3421E**: 8-bit register address (bit 1 = write) + 8-bit data, MSB first

## 3. Existing SPI Flash Interface

### Architecture

The picotiny SoC already has an SPI flash interface for boot and XIP (Execute In Place):

```
                    0x0000_0000 (XIP)           0x8100_0000 (Config)
                         |                            |
                    ┌────┴──────────────────────┬─────┴─────┐
                    │      SPI Flash Controller             │
                    │  ┌─────────────┐ ┌──────────────────┐ │
                    │  │  XIP Engine  │ │  Bitbang Engine  │ │
                    │  │  (HW auto)   │ │  (SW controlled) │ │
                    │  └──────┬───────┘ └────────┬─────────┘ │
                    │         └────────┬─────────┘           │
                    └─────────────────┬──────────────────────┘
                                      │
                              ┌───────┴───────┐
                              │   P25Q32U     │
                              │   SPI Flash   │
                              │   (32 Mbit)   │
                              └───────────────┘
                         Pins: 59(CLK) 60(MOSI) 61(MISO) 62(CS)
```

### SPI Flash Config Register (0x8100_0000)

The PICOQSPI struct in firmware maps to the bitbang SPI flash config register:

```c
typedef struct {
    union {
        volatile uint32_t REG;
        volatile uint16_t IOW;
        struct {
            volatile uint8_t IO;   // [7:0]  SPI data I/O pins
            volatile uint8_t OE;   // [15:8] Output enable per pin
            volatile uint8_t CFG;  // [23:16] Mode config (CRM, DSPI)
            volatile uint8_t EN;   // [31:24] Enable bitbang mode
        };
    };
} PICOQSPI;

#define QSPI0 ((PICOQSPI*)0x81000000)
```

### Bitbang SPI Flash Access

The boot ROM exposes a `spi_flashio()` function at a fixed address that firmware can call:

```c
#define FLASHIO_ENTRY_ADDR ((void *)0x80000054)
void (*spi_flashio)(uint8_t *pdata, int length, int wren) = FLASHIO_ENTRY_ADDR;

// Read flash ID example
uint8_t cmd[5] = {0x9F, 0, 0, 0, 0};  // JEDEC Read ID
spi_flashio(cmd, 5, 0);
// cmd[1..4] now contains manufacturer + device ID
```

### Pin Sharing Warning

The boot flash pins (59, 60, 61, 62) are shared between the FPGA configuration engine and user logic. The "Use MSPI as regular IO" option in Gowin EDA must be enabled to allow user-mode SPI flash access after boot. This is already enabled in the picotiny project. Do NOT attempt to use these pins for a second SPI peripheral; they are dedicated to the boot/XIP flash.

## 4. SD/TF Card SPI Interface

### Physical Connection

The Tang Nano 9K has a micro-SD card slot directly wired to Bank 2 GPIO:

| SD Signal | SPI Function | FPGA Pin | Bank |
|-----------|-------------|----------|------|
| CLK       | SCLK        | 36       | 2    |
| CMD       | MOSI        | 37       | 2    |
| DAT0      | MISO        | 39       | 2    |
| DAT3/CD   | CS          | 38       | 2    |

### SD Card SPI Protocol

SD cards in SPI mode follow a command/response protocol:

```
Command Frame (48 bits, MSB first):
┌────┬──────────┬────────────────────────────────┬─────────┬────┐
│ 01 │ cmd[5:0] │          argument[31:0]         │ crc[6:0]│ 1  │
└────┴──────────┴────────────────────────────────┴─────────┴────┘
 start  command          32-bit argument             CRC7    stop
```

### SD Card Initialization Sequence (SPI Mode)

1. Power on, wait 1 ms
2. Send 80+ clock cycles with CS high (74 minimum)
3. Assert CS low
4. Send CMD0 (GO_IDLE_STATE) -- must be at <400 kHz
5. Wait for R1 response = 0x01 (idle state)
6. Send CMD8 (SEND_IF_COND) with 0x1AA argument -- detects SDv2
7. Loop: Send ACMD41 (SD_SEND_OP_COND) with HCS bit until R1 = 0x00
8. Send CMD58 (READ_OCR) to check CCS bit (SDHC/SDXC detection)
9. Ramp SPI clock to operating speed (up to 25 MHz for SD, 6.3 MHz conservative)

### SD Card SPI Commands (Key Subset)

| Command | Value | Argument | Response | Description |
|---------|-------|----------|----------|-------------|
| CMD0    | 0x40  | 0x00000000 | R1 | Reset to idle |
| CMD8    | 0x48  | 0x000001AA | R7 | Interface condition |
| CMD17   | 0x51  | Block addr | R1 + data | Read single block |
| CMD24   | 0x58  | Block addr | R1 | Write single block |
| CMD55   | 0x77  | 0x00000000 | R1 | App command prefix |
| ACMD41  | 0x69  | 0x40000000 | R1 | Send OP cond (init) |
| CMD58   | 0x7A  | 0x00000000 | R3 | Read OCR |

### CST Pin Constraints for TF Card

```
// SD/TF Card SPI (directly routed on PCB)
IO_LOC "tf_sclk" 36;
IO_LOC "tf_mosi" 37;
IO_LOC "tf_cs"   38;
IO_LOC "tf_miso" 39;
IO_PORT "tf_sclk" IO_TYPE=LVCMOS33 DRIVE=8 SLEW_RATE=FAST;
IO_PORT "tf_mosi" IO_TYPE=LVCMOS33 DRIVE=8 SLEW_RATE=FAST;
IO_PORT "tf_cs"   IO_TYPE=LVCMOS33 DRIVE=8 PULL_MODE=UP;
IO_PORT "tf_miso" IO_TYPE=LVCMOS33 PULL_MODE=UP;
```

### Memory Map for SD SPI Controller

Proposed base address: `0x8400_0000` (next available peripheral slot).

| Offset | Name | Access | Description |
|--------|------|--------|-------------|
| 0x00   | TXDATA | W | Write byte to transmit FIFO |
| 0x04   | RXDATA | R | Read byte from receive FIFO |
| 0x08   | STATUS | R | Bit 0: TX ready, Bit 1: RX valid, Bit 2: busy |
| 0x0C   | CLKDIV | RW | Clock divider (bus_clk / (2 * (div+1))) |
| 0x10   | CONFIG | RW | Bit 0: CS assert, Bit 1: CPOL, Bit 2: CPHA |

## 5. MAX3421E USB Host via SPI

### Why MAX3421E

The MAX3421E is a dedicated USB host/peripheral controller that offloads the entire USB protocol to an external IC. The FPGA only needs a basic SPI master -- zero additional FPGA LUTs for USB.

| Property | Value |
|----------|-------|
| **IC** | Maxim MAX3421E |
| **Interface** | SPI slave, Mode 0, MSB first |
| **Max SPI Clock** | 26 MHz |
| **USB Speed** | Full-speed (12 Mbps) and Low-speed (1.5 Mbps) |
| **USB Class** | Host or Peripheral mode, software-selectable |
| **Cost** | $3-8 (breakout board with USB-A connector) |
| **Power** | 3.3V, ~50 mA typical |
| **Interrupt** | Active-low INT output (directly directly directly directly directly optional but recommended) |

### Wiring Plan

```
    Tang Nano 9K                    MAX3421E Breakout
    ┌──────────┐                   ┌─────────────────┐
    │          │                   │                 │
    │  Pin 26 ├──── SCLK ────────┤ SCK             │
    │  Pin 27 ├──── MOSI ────────┤ MOSI            │      ┌─────────┐
    │  Pin 28 ├──── MISO ────────┤ MISO            │      │  USB-A  │
    │  Pin 25 ├──── CS   ────────┤ SS              │      │ Female  │
    │  Pin 44 ├──── IRQ  ────────┤ INT (open-drain)│      │ Socket  │
    │          │                   │            VBUS ├──────┤         │
    │  3.3V   ├──── VCC  ────────┤ VCC        D+   ├──────┤         │
    │  GND    ├──── GND  ────────┤ GND        D-   ├──────┤         │
    │          │                   │            GND  ├──────┤         │
    └──────────┘                   └─────────────────┘      └─────────┘
```

**Pin Assignment (Left Header J1 + Right Header J2):**

|----------|----------|--------|-------|
| SPI_A_CS   | 25 | J1.1 | Active-low chip select |

### MAX3421E Register Map (Key Registers)

The MAX3421E uses 8-bit register addresses. Bit 1 of the address byte selects write (1) or read (0). An SPI transaction is always 2 bytes: address byte, then data byte.

```
SPI Write: [addr | 0x02] [data]    (bit 1 = 1 for write)
SPI Read:  [addr | 0x00] [0xFF]    (bit 1 = 0 for read, send dummy byte)
```

| Register | Address | Description |
|----------|---------|-------------|
| RCVFIFO  | 0x08    | USB receive FIFO (1-64 bytes) |
| SNDFIFO  | 0x10    | USB send FIFO (1-64 bytes) |
| RCVBC    | 0x30    | Receive byte count |
| SNDBC    | 0x38    | Send byte count |
| USBIRQ   | 0x68    | USB interrupt request (VBUS, NOVBUS, OSCOKIRQ) |
| USBIEN   | 0x70    | USB interrupt enable |
| USBCTL   | 0x78    | USB control (CHIPRES, PWRDOWN, CONNECT) |
| CPUCTL   | 0x80    | CPU control (IE = interrupt enable) |
| PINCTL   | 0x88    | Pin control (FDUPSPI, INTLEVEL, POSINT, GPXB/A) |
| REVISION | 0x90    | Silicon revision (should read 0x13) |
| HIRQ     | 0xC8    | Host interrupt request |
| HIEN     | 0xD0    | Host interrupt enable |
| MODE     | 0xD8    | Mode (HOST, LOWSPEED, HUBPRE, SOFKAENAB, SEPIRQ, DMPULLDN, DPPULLDN) |
| PERADDR  | 0xE0    | Peripheral address (USB device address) |
| HCTL     | 0xE8    | Host control (BUSRST, FRMRST, SAMPLEBUS, SIGRSM, RCVTOG, SNDTOG) |
| HXFR     | 0xF0    | Host transfer (endpoint + token type) |
| HRSL     | 0xF8    | Host result (HRSLT[3:0], JSTATUS, KSTATUS, SNDTOGRD, RCVTOGRD) |

### MAX3421E Initialization Sequence

```
1. Assert hardware reset (MAX_RST low for 200 us, then high)
2. Wait 100 ms for oscillator startup
3. Read REVISION register (should return 0x13)
4. Write PINCTL = 0x10 (full-duplex SPI)
5. Write USBCTL = 0x20 (CHIPRES = 1, chip reset)
6. Write USBCTL = 0x00 (CHIPRES = 0, release reset)
7. Wait for OSCOKIRQ in USBIRQ (oscillator ready)
8. Write MODE = 0xC1 (HOST mode, DPPULLDN, DMPULLDN, SEPIRQ)
9. Write HIEN = 0x2F (enable CONDET, FRAME, HXFR, RCV, SND interrupts)
10. Write CPUCTL = 0x01 (IE = interrupt enable)
11. Perform bus reset: Write HCTL = 0x01 (BUSRST), wait 50 ms, clear
12. Device is now enumerable
```

### USB HID Keyboard Polling (Simplified)

After enumeration and SET_CONFIGURATION:

```
Loop:
  1. Write HXFR = 0x00 (IN transfer to endpoint 0, or endpoint 1 for HID)
  2. Wait for HXFRDNIRQ in HIRQ
  3. Check HRSL for HRSLT = 0x00 (success) or 0x04 (NAK, no data)
  4. If success: read RCVBC for byte count, read RCVFIFO for HID report
  5. Parse 8-byte HID boot protocol report:
     Byte 0: Modifier keys (Ctrl, Shift, Alt, GUI)
     Byte 1: Reserved
     Bytes 2-7: Key codes (up to 6 simultaneous keys)
  6. Poll every 10 ms (USB HID poll interval)
```

## 6. Inter-Board SPI for Multi-Node Scaling

### Topology

Three Tang Nano 9K boards connected via SPI for distributed delta accumulation:

```
     Board 1 (Master)                Board 2 (Slave)
    ┌───────────────┐               ┌───────────────┐
    │  PicoRV32     │               │  PicoRV32     │
    │  + ATOMiK     │               │  + ATOMiK     │
    │               │               │               │
    │  SPI Master ──┼── SCLK ──────┼── SPI Slave   │
    │             ──┼── MOSI ──────┼──             │
    │             ──┼── MISO ──────┼──             │
    │         CS0 ──┼──────────────┼── SS          │
    │         CS1 ──┼──┐           └───────────────┘
    │               │  │
    │  HDMI Out     │  │            Board 3 (Slave)
    └───────────────┘  │           ┌───────────────┐
                       │           │  PicoRV32     │
                       │           │  + ATOMiK     │
                       │           │               │
                       └── SCLK ──┼── SPI Slave   │
                       ┌── MOSI ──┼──             │
                       ├── MISO ──┼──             │
                       └───────────┼── SS          │
                                   └───────────────┘

    Shared bus: SCLK, MOSI, MISO (directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly directly per-slave CS)
```

### Why SPI for Inter-Board

- **Speed:** 6.3 MHz SPI = ~6 Mbit/s unidirectional, ~750 KB/s sustained with framing
- **Simplicity:** 4 wires per slave (SCLK, MOSI, MISO, CS) -- no bus arbitration needed
- **Order-independent:** ATOMiK delta-state commutativity means deltas from Board 2 and Board 3 can arrive in any order and produce identical results
- **Resource cost:** One SPI master (~80 LUT) on Board 1, one SPI slave (~60 LUT) on each subordinate board

### Delta-Sync Protocol

Each board computes local deltas. The master board collects and merges them.

**Frame Format (32-bit delta payload):**

```
┌──────┬──────────┬───────────────────────────┬──────────┐
│ SYNC │  CMD[7:0]│       DELTA[31:0]          │ XOR_CHK  │
│ 0xA5 │          │                            │          │
└──────┴──────────┴───────────────────────────┴──────────┘
  1 byte  1 byte        4 bytes                  1 byte  = 7 bytes
```

**Commands:**

| CMD | Name | Description |
|-----|------|-------------|
| 0x01 | DELTA_PUSH | Master sends delta to slave for accumulation |
| 0x02 | DELTA_PULL | Master requests slave's accumulated delta |
| 0x03 | STATE_SYNC | Master sends current merged state |
| 0x04 | RESET      | Reset slave's accumulator |
| 0x80 | ACK        | Slave acknowledges command |
| 0x81 | DELTA_RESP | Slave responds with its accumulated delta |

**Merge Operation on Master:**

```
merged_state = initial_state XOR delta_local XOR delta_board2 XOR delta_board3
```

Because XOR is commutative and associative, the order of delta collection does not matter. This is the fundamental ATOMiK property that makes distributed accumulation trivial.

### Pin Assignment for Inter-Board SPI

Master (Board 1) uses SPI Bus B on left header:

| Function | FPGA Pin | Header | Notes |
|----------|----------|--------|-------|
| IB_CS0 (Board 2) | 29 | J1.5 | Chip select for slave board 2 |
| IB_SCLK | 30 | J1.6 | Shared clock |
| IB_MOSI | 33 | J1.7 | Data from master to slaves |
| IB_MISO | 34 | J1.8 | Data from slaves to master |
| IB_CS1 (Board 3) | 40 | J1.9 | Chip select for slave board 3 |

Slave boards connect the same signals to their own GPIO headers (matching pin numbers for consistency, or any available GPIO).

## 7. SPI Controller Implementation Options

### Option A: Bitbang SPI via GPIO (Simplest)

Use the existing GPIO peripheral at `0x8200_0000` to manually toggle SPI signals in firmware.

**Advantages:**
- Zero additional FPGA LUTs
- Works immediately with existing SoC
- Flexible -- any SPI mode, any timing

**Disadvantages:**
- CPU-intensive (each bit requires multiple MMIO writes)
- Slow: ~50 kHz effective SPI clock at 25.2 MHz CPU (each bit needs ~500 cycles for GPIO read-modify-write)
- Blocks CPU during transfers

**Best for:** Initial bring-up, testing wiring, one-time configuration reads.

### Option B: Soft-Core SPI Master via MMIO (Recommended)

A dedicated Verilog SPI master peripheral, memory-mapped like ATOMiK. The CPU writes bytes to a TX register, the hardware shifts them out at full SPI clock speed.

**Advantages:**
- Full-speed SPI (up to 12.6 MHz)
- CPU only writes/reads one register per byte
- Small: ~60-100 LUT per controller

**Disadvantages:**
- Requires RTL modification and re-synthesis
- Each controller is a single-master, single-slave (use CS for multi-slave)

**Best for:** Production use. MAX3421E, SD card, inter-board communication.

### Option C: Gowin EMPU SPI IP

The Gowin PicoRV32 IP (EMPU_M1) includes built-in SPI master and SPI slave peripherals (IPUG914). However, our picotiny SoC uses the open-source PicoRV32, not the Gowin EMPU IP. We cannot use the EMPU SPI peripherals directly.

To use Gowin IP SPI, we would need to either:
1. Instantiate the Gowin SPI Master IP as a standalone module and write our own bus wrapper, or
2. Migrate from picotiny to the full EMPU_M1 (a significant redesign).

**Recommendation:** Option B. A 60-100 LUT soft-core SPI master is trivial and gives us full control.

### Decision Matrix

| Criterion | Bitbang (A) | Soft-Core (B) | Gowin IP (C) |
|-----------|:-----------:|:--------------:|:------------:|
| LUT cost | 0 | 60-100 | ~200 |
| Max SPI clock | ~50 kHz | 12.6 MHz | 12.6 MHz |
| CPU overhead | Very high | Low (1 write/byte) | Low |
| Implementation time | 30 min | 2-4 hours | 1-2 days |
| Flexibility | Maximum | High | Medium |
| **Recommendation** | **Bring-up only** | **Use this** | **Skip** |

## 8. Soft-Core SPI Master (Verilog)

### Module: `spi_master.v`

A minimal, production-ready SPI master that fits the PicoRV32 valid/ready bus protocol.

```verilog
// =============================================================================
// Soft-Core SPI Master for PicoRV32
//
// MMIO-mapped SPI master with configurable clock divider and SPI mode.
// Directly compatible with PicoRV32 valid/ready bus protocol.
//
// Register Map:
//   0x00  TXDATA  (W)  - Write byte to transmit (starts transfer)
//   0x04  RXDATA  (R)  - Read received byte from last transfer
//   0x08  STATUS  (R)  - Bit 0: ready (1=idle), Bit 1: rx_valid
//   0x0C  CLKDIV  (RW) - Clock divider: spi_clk = bus_clk / (2*(div+1))
//   0x10  CONFIG  (RW) - Bit 0: CPOL, Bit 1: CPHA, Bit 2: CS assert
//
// Resource estimate: ~80 LUT, ~40 FF
// =============================================================================

`timescale 1ns / 1ps

module spi_master (
    input  wire        clk,
    input  wire        resetn,

    // PicoRV32 Bus Interface
    input  wire        mem_valid,
    input  wire [31:0] mem_addr,
    input  wire [31:0] mem_wdata,
    input  wire [3:0]  mem_wstrb,
    output reg         mem_ready,
    output reg  [31:0] mem_rdata,

    // SPI Signals
    output reg         spi_sclk,
    output reg         spi_mosi,
    input  wire        spi_miso,
    output reg         spi_cs_n
);

    // Registers
    reg [7:0]  tx_data;
    reg [7:0]  rx_data;
    reg [7:0]  rx_latch;       // Latched result of last completed transfer
    reg [15:0] clk_div;        // Clock divider
    reg        cfg_cpol;
    reg        cfg_cpha;
    reg        cfg_cs;         // CS assert control (1 = CS low)
    reg        rx_valid;

    // Shift engine state
    reg [3:0]  bit_cnt;        // 0..8 (0=idle, 1-8=shifting)
    reg [15:0] clk_cnt;        // Divider counter
    reg        sclk_phase;     // 0=first half, 1=second half
    reg        busy;

    wire ready = ~busy;
    wire [2:0] reg_sel = mem_addr[4:2];

    // SPI clock idle level
    wire sclk_idle = cfg_cpol;

    // =========================================================================
    // Bus Interface
    // =========================================================================

    always @(posedge clk or negedge resetn) begin
        if (!resetn) begin
            mem_ready  <= 1'b0;
            mem_rdata  <= 32'b0;
            tx_data    <= 8'b0;
            clk_div    <= 16'd3;    // Default: bus_clk / 8
            cfg_cpol   <= 1'b0;
            cfg_cpha   <= 1'b0;
            cfg_cs     <= 1'b0;
            rx_valid   <= 1'b0;
        end else begin
            mem_ready <= 1'b0;

            if (mem_valid && !mem_ready) begin
                mem_ready <= 1'b1;

                if (|mem_wstrb) begin
                    // Write
                    case (reg_sel)
                        3'b000: begin  // TXDATA
                            tx_data <= mem_wdata[7:0];
                            // Transfer start is handled by shift engine
                        end
                        3'b011: begin  // CLKDIV
                            clk_div <= mem_wdata[15:0];
                        end
                        3'b100: begin  // CONFIG
                            cfg_cpol <= mem_wdata[0];
                            cfg_cpha <= mem_wdata[1];
                            cfg_cs   <= mem_wdata[2];
                        end
                        default: ;
                    endcase
                end else begin
                    // Read
                    case (reg_sel)
                        3'b000: mem_rdata <= {24'b0, tx_data};
                        3'b001: begin   // RXDATA
                            mem_rdata <= {24'b0, rx_latch};
                            rx_valid  <= 1'b0;
                        end
                        3'b010: mem_rdata <= {30'b0, rx_valid, ready};
                        3'b011: mem_rdata <= {16'b0, clk_div};
                        3'b100: mem_rdata <= {29'b0, cfg_cs, cfg_cpha, cfg_cpol};
                        default: mem_rdata <= 32'b0;
                    endcase
                end
            end
        end
    end

    // =========================================================================
    // SPI Shift Engine
    // =========================================================================

    // Detect write to TXDATA (start transfer)
    reg tx_start;
    always @(posedge clk or negedge resetn) begin
        if (!resetn)
            tx_start <= 1'b0;
        else
            tx_start <= mem_valid && !mem_ready && (|mem_wstrb) && (reg_sel == 3'b000);
    end

    always @(posedge clk or negedge resetn) begin
        if (!resetn) begin
            busy       <= 1'b0;
            bit_cnt    <= 4'd0;
            clk_cnt    <= 16'd0;
            sclk_phase <= 1'b0;
            spi_sclk   <= 1'b0;
            spi_mosi   <= 1'b0;
            spi_cs_n   <= 1'b1;
            rx_data    <= 8'b0;
            rx_latch   <= 8'b0;
        end else begin
            // CS control
            spi_cs_n <= ~cfg_cs;

            if (!busy) begin
                spi_sclk <= sclk_idle;

                if (tx_start && ready) begin
                    busy       <= 1'b1;
                    bit_cnt    <= 4'd8;
                    clk_cnt    <= 16'd0;
                    sclk_phase <= 1'b0;
                    rx_data    <= 8'b0;

                    // CPHA=0: set MOSI on leading edge (now)
                    if (!cfg_cpha)
                        spi_mosi <= tx_data[7];
                end
            end else begin
                // Divider tick
                if (clk_cnt < clk_div) begin
                    clk_cnt <= clk_cnt + 1'b1;
                end else begin
                    clk_cnt <= 16'd0;

                    if (!sclk_phase) begin
                        // First half -> toggle SCLK
                        spi_sclk   <= ~sclk_idle;
                        sclk_phase <= 1'b1;

                        if (cfg_cpha) begin
                            // CPHA=1: shift out data on first edge
                            spi_mosi <= tx_data[7];
                        end else begin
                            // CPHA=0: sample MISO on first edge
                            rx_data <= {rx_data[6:0], spi_miso};
                        end
                    end else begin
                        // Second half -> toggle SCLK back
                        spi_sclk   <= sclk_idle;
                        sclk_phase <= 1'b0;

                        if (cfg_cpha) begin
                            // CPHA=1: sample MISO on second edge
                            rx_data <= {rx_data[6:0], spi_miso};
                        end else begin
                            // CPHA=0: shift out next bit on second edge
                            tx_data <= {tx_data[6:0], 1'b0};
                        end

                        if (cfg_cpha)
                            tx_data <= {tx_data[6:0], 1'b0};

                        bit_cnt <= bit_cnt - 1'b1;

                        if (bit_cnt == 4'd1) begin
                            // Last bit done
                            busy     <= 1'b0;
                            rx_latch <= cfg_cpha ?
                                        {rx_data[6:0], spi_miso} :
                                        {rx_data[6:0], rx_data[0]};
                            rx_valid <= 1'b1;
                        end
                    end
                end
            end
        end
    end

endmodule
```

### 9.1 Hardware SPI Driver (for `spi_master.v`)

```c
// =============================================================================
// spi_drv.h -- SPI Driver for ATOMiK PicoRV32 SoC
// =============================================================================

#ifndef SPI_DRV_H
#define SPI_DRV_H

#include <stdint.h>

typedef struct {
    volatile uint32_t TXDATA;   // 0x00: Write byte to transmit
    volatile uint32_t RXDATA;   // 0x04: Read received byte
    volatile uint32_t STATUS;   // 0x08: Bit 0=ready, Bit 1=rx_valid
    volatile uint32_t CLKDIV;   // 0x0C: Clock divider
    volatile uint32_t CONFIG;   // 0x10: Bit 0=CPOL, 1=CPHA, 2=CS
} SPI_TypeDef;

#define SPI_A ((SPI_TypeDef *)0x84000000)   // MAX3421E
#define SPI_B ((SPI_TypeDef *)0x85000000)   // SD Card / Inter-board

#define SPI_STATUS_READY    (1 << 0)
#define SPI_STATUS_RXVALID  (1 << 1)
#define SPI_CONFIG_CPOL     (1 << 0)
#define SPI_CONFIG_CPHA     (1 << 1)
#define SPI_CONFIG_CS       (1 << 2)

// Wait until SPI is idle
static inline void spi_wait(SPI_TypeDef *spi) {
    while (!(spi->STATUS & SPI_STATUS_READY))
        ;
}

// Initialize SPI port
static inline void spi_init(SPI_TypeDef *spi, uint16_t divider, uint8_t mode) {
    spi->CLKDIV = divider;
    spi->CONFIG = (mode & 0x03);  // CPOL and CPHA from mode bits
}

// Assert chip select (active-low)
static inline void spi_cs_low(SPI_TypeDef *spi) {
    spi->CONFIG |= SPI_CONFIG_CS;
}

// Deassert chip select
static inline void spi_cs_high(SPI_TypeDef *spi) {
    spi->CONFIG &= ~SPI_CONFIG_CS;
}

// Transfer one byte (full duplex)
static inline uint8_t spi_xfer(SPI_TypeDef *spi, uint8_t tx) {
    spi_wait(spi);
    spi->TXDATA = tx;
    spi_wait(spi);
    return (uint8_t)(spi->RXDATA);
}

// Send a buffer (ignore received data)
static inline void spi_send(SPI_TypeDef *spi, const uint8_t *buf, uint32_t len) {
    for (uint32_t i = 0; i < len; i++) {
        spi_xfer(spi, buf[i]);
    }
}

// Receive a buffer (send 0xFF dummy bytes)
static inline void spi_recv(SPI_TypeDef *spi, uint8_t *buf, uint32_t len) {
    for (uint32_t i = 0; i < len; i++) {
        buf[i] = spi_xfer(spi, 0xFF);
    }
}

#endif // SPI_DRV_H
```

### 9.2 Bitbang SPI Driver (Zero LUT Cost)

Uses the existing GPIO peripheral at `0x8200_0000`. Good for initial bring-up before the hardware SPI master is synthesized.

```c
// =============================================================================
// spi_bitbang.h -- Bitbang SPI via GPIO for ATOMiK PicoRV32 SoC
//
// Uses GPIO pins directly. Slow (~50 kHz) but zero FPGA resources.
// =============================================================================

#ifndef SPI_BITBANG_H
#define SPI_BITBANG_H

#include <stdint.h>

// GPIO register block (already in picotiny SoC)
typedef struct {
    volatile uint32_t OUT;
    volatile uint32_t IN;
    volatile uint32_t OE;
} PICOGPIO;

#define GPIO0 ((PICOGPIO *)0x82000000)

// Pin bit positions within GPIO register
// These must match your CST constraints for the GPIO pins
// Example: GPIO bits 0-3 mapped to header pins
#define BB_SPI_CS_BIT    (1 << 0)   // GPIO bit for CS
#define BB_SPI_SCLK_BIT  (1 << 1)   // GPIO bit for SCLK
#define BB_SPI_MOSI_BIT  (1 << 2)   // GPIO bit for MOSI
#define BB_SPI_MISO_BIT  (1 << 3)   // GPIO bit for MISO

static inline void bb_spi_init(void) {
    // Set CS, SCLK, MOSI as outputs; MISO as input
    GPIO0->OE |= (BB_SPI_CS_BIT | BB_SPI_SCLK_BIT | BB_SPI_MOSI_BIT);
    GPIO0->OE &= ~BB_SPI_MISO_BIT;

    // CS high (deasserted), SCLK low (Mode 0 idle)
    GPIO0->OUT |= BB_SPI_CS_BIT;
    GPIO0->OUT &= ~BB_SPI_SCLK_BIT;
}

static inline void bb_spi_cs_low(void) {
    GPIO0->OUT &= ~BB_SPI_CS_BIT;
}

static inline void bb_spi_cs_high(void) {
    GPIO0->OUT |= BB_SPI_CS_BIT;
}

// Transfer one byte, SPI Mode 0 (CPOL=0, CPHA=0), MSB first
static inline uint8_t bb_spi_xfer(uint8_t tx) {
    uint8_t rx = 0;

    for (int i = 7; i >= 0; i--) {
        // Set MOSI
        if (tx & (1 << i))
            GPIO0->OUT |= BB_SPI_MOSI_BIT;
        else
            GPIO0->OUT &= ~BB_SPI_MOSI_BIT;

        // Rising edge of SCLK (sample MISO)
        GPIO0->OUT |= BB_SPI_SCLK_BIT;

        // Read MISO
        if (GPIO0->IN & BB_SPI_MISO_BIT)
            rx |= (1 << i);

        // Falling edge of SCLK
        GPIO0->OUT &= ~BB_SPI_SCLK_BIT;
    }

    return rx;
}

#endif // SPI_BITBANG_H
```

### 9.3 MAX3421E USB HID Driver Skeleton

```c
// =============================================================================
// max3421e.h -- MAX3421E USB Host Driver for ATOMiK PicoRV32 SoC
// =============================================================================

#ifndef MAX3421E_H
#define MAX3421E_H

#include <stdint.h>
#include "spi_drv.h"

// MAX3421E register addresses
#define MAX_RCVFIFO   0x08
#define MAX_SNDFIFO   0x10
#define MAX_SUDFIFO   0x20
#define MAX_RCVBC     0x30
#define MAX_SNDBC     0x38
#define MAX_USBIRQ    0x68
#define MAX_USBIEN    0x70
#define MAX_USBCTL    0x78
#define MAX_CPUCTL    0x80
#define MAX_PINCTL    0x88
#define MAX_REVISION  0x90
#define MAX_HIRQ      0xC8
#define MAX_HIEN      0xD0
#define MAX_MODE      0xD8
#define MAX_PERADDR   0xE0
#define MAX_HCTL      0xE8
#define MAX_HXFR      0xF0
#define MAX_HRSL      0xF8

// HIRQ bits
#define HIRQ_BUSEVENT (1 << 0)
#define HIRQ_RWU      (1 << 1)
#define HIRQ_RCVDAV   (1 << 2)
#define HIRQ_SNDBAV   (1 << 3)
#define HIRQ_SUSDNIRQ (1 << 4)
#define HIRQ_CONDET   (1 << 5)
#define HIRQ_FRAMEIRQ (1 << 6)
#define HIRQ_HXFRDNIRQ (1 << 7)

// HRSL result codes
#define HRSL_SUCCESS  0x00
#define HRSL_BUSY     0x01
#define HRSL_BADREQ   0x02
#define HRSL_UNDEF    0x03
#define HRSL_NAK      0x04
#define HRSL_STALL    0x05
#define HRSL_TOGERR   0x06
#define HRSL_WRONGPID 0x07
#define HRSL_BADBC    0x08
#define HRSL_PIDERR   0x09
#define HRSL_PKTERR   0x0A
#define HRSL_CRCERR   0x0B
#define HRSL_KERR     0x0C
#define HRSL_JERR     0x0D
#define HRSL_TIMEOUT  0x0E
#define HRSL_BABBLE   0x0F

// HID boot protocol keyboard report
typedef struct {
    uint8_t modifiers;     // Ctrl, Shift, Alt, GUI
    uint8_t reserved;
    uint8_t keys[6];       // Up to 6 simultaneous key codes
} hid_keyboard_report_t;

// SPI register access
static inline void max_write_reg(uint8_t reg, uint8_t val) {
    spi_cs_low(SPI_A);
    spi_xfer(SPI_A, reg | 0x02);   // Bit 1 = write
    spi_xfer(SPI_A, val);
    spi_cs_high(SPI_A);
}

static inline uint8_t max_read_reg(uint8_t reg) {
    uint8_t val;
    spi_cs_low(SPI_A);
    spi_xfer(SPI_A, reg);           // Bit 1 = 0 for read
    val = spi_xfer(SPI_A, 0xFF);    // Dummy byte, read response
    spi_cs_high(SPI_A);
    return val;
}

// Read multiple bytes from FIFO
static inline void max_read_fifo(uint8_t reg, uint8_t *buf, uint8_t len) {
    spi_cs_low(SPI_A);
    spi_xfer(SPI_A, reg);
    for (uint8_t i = 0; i < len; i++)
        buf[i] = spi_xfer(SPI_A, 0xFF);
    spi_cs_high(SPI_A);
}

// Write multiple bytes to FIFO
static inline void max_write_fifo(uint8_t reg, const uint8_t *buf, uint8_t len) {
    spi_cs_low(SPI_A);
    spi_xfer(SPI_A, reg | 0x02);
    for (uint8_t i = 0; i < len; i++)
        spi_xfer(SPI_A, buf[i]);
    spi_cs_high(SPI_A);
}

// Initialize MAX3421E
static inline int max_init(void) {
    // SPI Mode 0, 6.3 MHz (divider=1 at 25.2 MHz bus)
    spi_init(SPI_A, 1, 0);

    // Full-duplex SPI mode
    max_write_reg(MAX_PINCTL, 0x10);

    // Chip reset
    max_write_reg(MAX_USBCTL, 0x20);
    max_write_reg(MAX_USBCTL, 0x00);

    // Wait for oscillator (poll OSCOKIRQ)
    uint32_t timeout = 100000;
    while (!(max_read_reg(MAX_USBIRQ) & 0x01) && --timeout)
        ;
    if (!timeout)
        return -1;  // Oscillator failed to start

    // Verify silicon revision
    uint8_t rev = max_read_reg(MAX_REVISION);
    if (rev != 0x13)
        return -2;  // Wrong chip or bad SPI connection

    // Host mode, pull-downs on D+/D-, separate IRQ pin
    max_write_reg(MAX_MODE, 0xC1);

    // Enable key host interrupts
    max_write_reg(MAX_HIEN, 0xE5);

    // Global interrupt enable
    max_write_reg(MAX_CPUCTL, 0x01);

    return 0;
}

// Perform USB bus reset
static inline void max_bus_reset(void) {
    max_write_reg(MAX_HCTL, 0x01);   // BUSRST

    // Wait for bus reset to complete (~50 ms)
    // In production, use a timer. Here, spin-wait.
    for (volatile int i = 0; i < 500000; i++)
        ;

    // Clear bus event IRQ
    max_write_reg(MAX_HIRQ, HIRQ_BUSEVENT);
}

// Issue a control transfer (SETUP stage)
static inline int max_control_setup(uint8_t addr, const uint8_t *setup_pkt) {
    max_write_reg(MAX_PERADDR, addr);
    max_write_fifo(MAX_SUDFIFO, setup_pkt, 8);
    max_write_reg(MAX_HXFR, 0x10);   // SETUP token

    // Wait for transfer done
    uint32_t timeout = 100000;
    while (!(max_read_reg(MAX_HIRQ) & HIRQ_HXFRDNIRQ) && --timeout)
        ;
    max_write_reg(MAX_HIRQ, HIRQ_HXFRDNIRQ);  // Clear IRQ

    uint8_t result = max_read_reg(MAX_HRSL) & 0x0F;
    return (result == HRSL_SUCCESS) ? 0 : -result;
}

// Poll HID interrupt endpoint for keyboard data
static inline int max_poll_hid(uint8_t ep, hid_keyboard_report_t *report) {
    // IN transfer to endpoint
    max_write_reg(MAX_HXFR, ep);      // IN token to endpoint

    uint32_t timeout = 10000;
    while (!(max_read_reg(MAX_HIRQ) & HIRQ_HXFRDNIRQ) && --timeout)
        ;
    max_write_reg(MAX_HIRQ, HIRQ_HXFRDNIRQ);

    uint8_t result = max_read_reg(MAX_HRSL) & 0x0F;

    if (result == HRSL_NAK)
        return 0;   // No data available (normal)
    if (result != HRSL_SUCCESS)
        return -result;

    uint8_t bc = max_read_reg(MAX_RCVBC);
    if (bc >= 8) {
        max_read_fifo(MAX_RCVFIFO, (uint8_t *)report, 8);
    }

    return bc;
}

#endif // MAX3421E_H
```

### 9.4 SD Card SPI Driver Skeleton

```c
// =============================================================================
// sd_spi.h -- SD Card SPI Driver for ATOMiK PicoRV32 SoC
// =============================================================================

#ifndef SD_SPI_H
#define SD_SPI_H

#include <stdint.h>
#include "spi_drv.h"

#define SD_SPI SPI_B

// SD commands
#define SD_CMD0   (0x40 | 0)    // GO_IDLE_STATE
#define SD_CMD8   (0x40 | 8)    // SEND_IF_COND
#define SD_CMD17  (0x40 | 17)   // READ_SINGLE_BLOCK
#define SD_CMD24  (0x40 | 24)   // WRITE_BLOCK
#define SD_CMD55  (0x40 | 55)   // APP_CMD prefix
#define SD_CMD58  (0x40 | 58)   // READ_OCR
#define SD_ACMD41 (0x40 | 41)   // SD_SEND_OP_COND

// Send SD command and get R1 response
static inline uint8_t sd_send_cmd(uint8_t cmd, uint32_t arg) {
    spi_xfer(SD_SPI, cmd);
    spi_xfer(SD_SPI, (arg >> 24) & 0xFF);
    spi_xfer(SD_SPI, (arg >> 16) & 0xFF);
    spi_xfer(SD_SPI, (arg >>  8) & 0xFF);
    spi_xfer(SD_SPI, (arg >>  0) & 0xFF);

    // CRC (only matters for CMD0 and CMD8)
    uint8_t crc = 0xFF;
    if (cmd == SD_CMD0)  crc = 0x95;
    if (cmd == SD_CMD8)  crc = 0x87;
    spi_xfer(SD_SPI, crc);

    // Wait for response (R1: MSB = 0)
    uint8_t r1;
    for (int i = 0; i < 10; i++) {
        r1 = spi_xfer(SD_SPI, 0xFF);
        if (!(r1 & 0x80))
            break;
    }
    return r1;
}

// Initialize SD card in SPI mode
// Returns 0 on success, negative on error
static inline int sd_init(void) {
    // Slow clock for init (<400 kHz)
    // bus_clk = 25.2 MHz, div=31 => 25.2/(2*32) = 394 kHz
    spi_init(SD_SPI, 31, 0);

    // CS high, send 80+ clock pulses
    spi_cs_high(SD_SPI);
    for (int i = 0; i < 10; i++)
        spi_xfer(SD_SPI, 0xFF);

    // CMD0: reset to idle
    spi_cs_low(SD_SPI);
    uint8_t r1 = sd_send_cmd(SD_CMD0, 0);
    spi_cs_high(SD_SPI);
    spi_xfer(SD_SPI, 0xFF);

    if (r1 != 0x01)
        return -1;  // Card did not enter idle state

    // CMD8: interface condition (SDv2 check)
    spi_cs_low(SD_SPI);
    r1 = sd_send_cmd(SD_CMD8, 0x000001AA);
    if (r1 == 0x01) {
        // SDv2 card -- read 4-byte R7 response
        uint8_t r7[4];
        for (int i = 0; i < 4; i++)
            r7[i] = spi_xfer(SD_SPI, 0xFF);
        // Verify echo pattern
        if (r7[2] != 0x01 || r7[3] != 0xAA) {
            spi_cs_high(SD_SPI);
            return -2;
        }
    }
    spi_cs_high(SD_SPI);
    spi_xfer(SD_SPI, 0xFF);

    // ACMD41: initialize card (loop until ready)
    for (int attempt = 0; attempt < 1000; attempt++) {
        // CMD55 (APP_CMD prefix)
        spi_cs_low(SD_SPI);
        sd_send_cmd(SD_CMD55, 0);
        spi_cs_high(SD_SPI);
        spi_xfer(SD_SPI, 0xFF);

        // ACMD41 with HCS bit
        spi_cs_low(SD_SPI);
        r1 = sd_send_cmd(SD_ACMD41, 0x40000000);
        spi_cs_high(SD_SPI);
        spi_xfer(SD_SPI, 0xFF);

        if (r1 == 0x00)
            break;  // Card is ready
    }

    if (r1 != 0x00)
        return -3;  // Card failed to initialize

    // Switch to fast clock for data transfer
    // div=1 => 25.2/(2*2) = 6.3 MHz
    spi_init(SD_SPI, 1, 0);

    return 0;
}

// Read a 512-byte block from SD card
// For SDHC/SDXC: block_addr is the block number (not byte address)
static inline int sd_read_block(uint32_t block_addr, uint8_t *buf) {
    spi_cs_low(SD_SPI);

    uint8_t r1 = sd_send_cmd(SD_CMD17, block_addr);
    if (r1 != 0x00) {
        spi_cs_high(SD_SPI);
        return -1;
    }

    // Wait for data token (0xFE)
    uint32_t timeout = 100000;
    uint8_t token;
    do {
        token = spi_xfer(SD_SPI, 0xFF);
    } while (token == 0xFF && --timeout);

    if (token != 0xFE) {
        spi_cs_high(SD_SPI);
        return -2;
    }

    // Read 512 bytes of data
    spi_recv(SD_SPI, buf, 512);

    // Read and discard 2-byte CRC
    spi_xfer(SD_SPI, 0xFF);
    spi_xfer(SD_SPI, 0xFF);

    spi_cs_high(SD_SPI);
    spi_xfer(SD_SPI, 0xFF);

    return 0;
}

// Write a 512-byte block to SD card
static inline int sd_write_block(uint32_t block_addr, const uint8_t *buf) {
    spi_cs_low(SD_SPI);

    uint8_t r1 = sd_send_cmd(SD_CMD24, block_addr);
    if (r1 != 0x00) {
        spi_cs_high(SD_SPI);
        return -1;
    }

    // Send data token
    spi_xfer(SD_SPI, 0xFE);

    // Send 512 bytes of data
    spi_send(SD_SPI, buf, 512);

    // Send dummy CRC
    spi_xfer(SD_SPI, 0xFF);
    spi_xfer(SD_SPI, 0xFF);

    // Read data response
    uint8_t resp = spi_xfer(SD_SPI, 0xFF);
    if ((resp & 0x1F) != 0x05) {
        spi_cs_high(SD_SPI);
        return -2;  // Write rejected
    }

    // Wait for card to finish programming
    uint32_t timeout = 500000;
    while (spi_xfer(SD_SPI, 0xFF) == 0x00 && --timeout)
        ;

    spi_cs_high(SD_SPI);
    spi_xfer(SD_SPI, 0xFF);

    return timeout ? 0 : -3;
}

#endif // SD_SPI_H
```

### Full System Budget with All SPI

| Component | LUT | % of 8,640 | Status |
|-----------|-----|-----------|--------|
| PicoRV32 CPU | ~3,100 | 35.9% | Deployed |
| HDMI Output | ~400 | 4.6% | Deployed |

| UART | ~50 | 0.6% | Deployed |

| **Subtotal (current SoC)** | **~3,838** | **44.4%** | |
| SPI Master A (MAX3421E) | ~90 | 1.0% | Planned |
| SPI Master B (SD Card) | ~90 | 1.0% | Planned |
| SPI Master C (Inter-Board) | ~90 | 1.0% | Planned |
| Bus mux expansion | ~30 | 0.3% | Planned |

Adding all three SPI controllers costs only 300 LUT (3.5% of the FPGA). This leaves 52% headroom for the HDMI text framebuffer (~500-1,000 LUT), expanded ATOMiK banks, and future peripherals.

### Timing Impact

SPI controllers run at the bus clock (25.2 MHz) and are pure combinational/sequential logic with short paths. They will not create timing pressure on the existing clock domains. No impact on ATOMiK Fmax (100.2 MHz) or CPU Fmax (30.6 MHz) is expected.

## Appendix: SPI Clock Divider Quick Reference

For the `spi_master.v` module, the SPI clock frequency is:

```
spi_clk = bus_clk / (2 * (CLKDIV + 1))
```

At 25.2 MHz bus clock:

| CLKDIV | SPI Clock | Period | Use Case |
|--------|-----------|--------|----------|
| 0 | 12.60 MHz | 79 ns | Maximum (short traces only) |
| 1 | 6.30 MHz | 159 ns | SD card fast, MAX3421E |
| 3 | 3.15 MHz | 317 ns | Safe default, breadboard |
| 7 | 1.575 MHz | 635 ns | Conservative |
| 15 | 787.5 kHz | 1.27 us | Slow peripherals |
| 31 | 393.8 kHz | 2.54 us | SD card init (<400 kHz) |
| 63 | 196.9 kHz | 5.08 us | Very slow |
