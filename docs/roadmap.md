# Roadmap

ATOMiK's public roadmap separates what is live, what is validated, and what is
planned.

## Live Today

- Current ATOMiK Desk prototype screenshot from live hardware.
- Public software and formal proof work.
- Hardware validation and board-run artifacts where recorded.
- Evidence labels and claims registry for public claims.

## Near-Term Evaluation Path

1. Explore the primitive in software.
2. Test it against a real workload or trace.
3. Move into hardware-backed evaluation where justified.
4. Assess integration into broader architecture.

## What Not To Claim Yet

- ATOMiK Desk is not presented as a market-ready desktop product.
- Concept visuals are not current commercial UI.
- Synthesis ceilings are not live-board measurements.
- Projected economics or performance must not be phrased as results.
- Broad production traction requires referenceable proof before public use.

## Roadmap Disclaimer

Roadmap items may change. They should guide evaluation conversations, not stand
in for current product commitments.
