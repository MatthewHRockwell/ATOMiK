# Picking this repo up on another machine

`git clone https://github.com/MatthewHRockwell/ATOMiK.git` gives you every
source file, doc and proof artifact. It does **not** give you the ~10 GB of
vendor clones and FPGA build output that are deliberately gitignored.

Here is what to re-fetch or rebuild, and what you can skip until you need it.

## Needed only for FPGA / ASIC work

| Path (gitignored) | What it is | How to get it back |
| --- | --- | --- |
| `hardware/asic/caravel_atomik/` | Efabless Caravel harness + sky130 PDK (~8 GB) | Re-clone Caravel and run its `make setup` / volare PDK install |
| `hardware/zynq/alinx_reference/` | ALINX vendor reference designs (~2.2 GB, its own git repo) | Re-clone from ALINX; note the board here is **CLG484**, not the CLG400 ALINX documents |
| `hardware/zynq/litex-build*/` | 25 LiteX/Vivado build trees (~96k files) | Rebuild from `hardware/zynq/litex/soc_nax64_atomik.py` |
| `hardware/asic/sky130/`, `hardware/asic/asic_output/`, `openlane/runs/` | OpenLane flow output | Re-run the flow |
| `.Xil/`, `.gen/`, `.srcs/` | Vivado project scratch | Regenerated by Vivado |

Rebuilding a bitstream needs Vivado installed — if the new laptop is for
software/website work only, you can ignore this whole section.

## Needed only for board bring-up

| Path (gitignored) | How to get it back |
| --- | --- |
| `hardware/zynq/ubuntu/rootfs/`, `*.cpio`, `*.cpio.gz` | Rebuilt by the scripts in `hardware/zynq/ubuntu/` from the upstream `ubuntu-base-24.04.4-base-riscv64` tarball |
| `hardware/zynq/fsbl_build/BOOT.bin.old`, `.prefix` | Intermediate FSBL images, regenerated by the FSBL build |
| Compiled probes under `hardware/zynq/{test,ps_loader}/`, `atomik_os/tools/fbcrop`, `software/atomik-sync`, `software/atomik-agent-mem` | `make` in the directory beside the source |

## Just works after clone

- `software/` — Python SDK and benchmarks. `pytest` (399 tests) runs green with
  no extra setup; the pre-commit hook runs ruff + the suite.
- `website/` — `npm install && npm run dev`. `.next/` is build output.
- `atomik_os/` — `make host-shot` renders the real UI to a PNG on the laptop,
  no board required.
- `hardware/zynq/test/`, `rtl/`, `sim/` — all RTL, XDC and probe sources.
- `atomik_os/docs/screenshots/` — on-board fb2png proof captures.

## Branch layout

- `main` — released/published state.
- `parallel-banks-hw-and-hdmi-proof` — the active branch; contains the GTM,
  contract-bench and USB/HID work. This is where to resume.
