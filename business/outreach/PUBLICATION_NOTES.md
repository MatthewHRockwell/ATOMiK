# Outreach Publication Notes

Most files in this directory are historical application drafts, VC email drafts,
social posts, or follow-up templates. They are not current public claim copy
unless explicitly listed as public-safe in `../PUBLICATION_NOTES.md`.

Before sending any file from this directory externally:

1. Replace hard performance, power, cost, production, customer, or market-size
   claims with evidence-labeled language.
2. Attach the relevant artifact from `../../results/claims_registry.yaml` or
   the current docs.
3. Use request-based evaluation CTAs rather than old free-tier, pilot, or
   production-readiness language.
4. Keep v0.38-H claims pending until a recorded screenshot or demo artifact is
   available.

Public-safe outreach starting points are:

- `design_partner_outreach.md`
- `email_sequences.md`

All other outreach drafts require review before use.
