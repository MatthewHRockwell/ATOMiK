# GitHub Sponsors Setup Guide

## To Enable (Matt must do this manually):

1. Go to https://github.com/sponsors/MatthewHRockwell/dashboard
2. Click "Get started" or "Join the waitlist"
3. Fill in:
   - **Country:** United States
   - **Bank:** Connect via Stripe (reuse your existing Stripe if you have one)
4. Create tiers (suggested below)
5. FUNDING.yml is already created in the repo
