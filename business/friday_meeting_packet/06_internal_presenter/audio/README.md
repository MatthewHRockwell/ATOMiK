# Internal Presenter Audio

Internal prep assets for rehearsing the Friday investor presentation. Do not include these files in the clean external send package unless intentionally shared.

## Files

- `ATOMiK_Investor_Deck_10_Minute_Rehearsal.mp3` - 10-minute narrated walkthrough keyed to `01_front_of_room/ATOMiK_Investor_Deck.pdf`.
- `ATOMiK_Investor_Deck_10_Minute_Rehearsal_Script.md` - editable narration source.
- `ATOMiK_Investor_Deck_10_Minute_Rehearsal_TTS.txt` - plain-text TTS input used to generate the MP3.
- `ATOMiK_Investor_Deck_10_Minute_Rehearsal.vtt` - subtitles / transcript timing.

## Use

Use the audio to keep the pitch on track: pain, proof, business path, risks, and ask. It is not intended for memorization or external distribution.
