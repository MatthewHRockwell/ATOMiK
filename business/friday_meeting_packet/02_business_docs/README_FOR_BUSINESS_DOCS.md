# README For Business Docs

This folder is a source/support layer for the Friday pitch package. Do not send the whole folder by default.

## Public / Front-Of-Room

Use these for the live meeting or immediate lightweight follow-up:

- Investor deck
- 5-minute backup deck
- One-pager
- Executive summary

The business plan is not public/front-of-room. Treat it as controlled diligence.

## Controlled Diligence

Use these only after a serious follow-up request or when the recipient understands the proof boundaries:

- `DATA_ROOM_INDEX.md`
- `INVESTOR_BRIEF.md`
- `LICENSING_IP_OVERVIEW.md`
- `PROOF_PACKET.md`
- `CLAIMS_EVIDENCE_MATRIX.md`
- Business plan
- Financial diligence materials
- Product/technical overview
- Legal/IP materials

## Internal Meeting Support

Use these to run the Friday call. Do not send externally unless intentionally shared:

## Claim Rules

- Use `FORMAL_PROOF` only for directly audited formal properties; otherwise say `SOFTWARE_VALIDATED / proof work present`.
- Quote performance only with artifact, workload, context, and caveat.
- Treat battery, heat, cooling, water, power-bill, footprint, and customer savings as evaluation targets unless measured in the relevant environment.
- Do not claim universal speedup, production readiness, signed traction, or a production ASIC without artifact-backed support.

## Best Current Use

- Live pitch: investor deck.
- Leave-behind: one-pager.
- Post-call summary: executive summary.
- Diligence: proof packet, claims matrix, investor brief, business plan, financials, legal/IP, and product/technical overview.
- Internal facilitation: talking points and AAN feedback sheet.
