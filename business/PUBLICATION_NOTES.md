High-risk legacy files include old score-package, Cosmos Cookoff, launch-post,
marketing-post, meeting-prep, and VC-diligence documents. They contain historical
performance, TAM, valuation, and revenue language that should not be sent into
this pitch without a fresh evidence review.

Many legacy files now carry an inline `Publication status` banner. If a file
does not yet have one, this note still applies: it is not current public claim
copy unless listed in the Current Investor Packet or Public-Safe Starting Points sections above.

Before sharing any review-required material externally:

1. Check every performance, power, cost, customer, production, or traction claim
   against `../results/claims_registry.yaml`.
2. Add the correct evidence label from `../docs/evidence-labels.md`.
3. Replace any unsupported result language with `PROJECTED`, `CONCEPTUAL`, or
   `ROADMAP` wording.
4. Remove stale pricing/free-trial language and use request-based evaluation
   access unless a counsel-reviewed commercial offer supersedes it.
