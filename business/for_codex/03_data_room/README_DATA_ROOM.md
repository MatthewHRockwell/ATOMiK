# ATOMiK Data Room README

Last updated: 2026-05-28

This folder is controlled diligence for serious investor, partner, legal, and technical follow-up. Do not send the full folder by default.

## Public / Lightweight Follow-Up

Use these before a diligence path is active:

- Investor deck
- One-pager
- Executive summary

## Controlled Diligence

Use these after serious follow-up interest, and only with the current proof boundaries intact:

- Business plan
- Financial diligence memo
- Product/technical overview
- Customer pipeline
- Legal formation summary
- Team overview
- Proof packet and claims/evidence matrix

## NDA / Counsel-Controlled

Use these only under NDA, counsel control, or a clearly approved diligence path:

- Full provisional patent PDF
- Founder IP assignment documents
- Entity records
- Cap table drafts
- SAFE drafts or side letters
- Private source artifacts
- Customer traces, logs, workloads, or partner-specific evaluation data

## Send Policy

- Do not present the Business Plan as front-of-room collateral.
- Do not present the Customer Pipeline as traction unless a meeting, LOI, paid evaluation, or customer artifact exists.
- Do not circulate the full provisional patent broadly; use the investor-safe patent summary first.
- Do not claim Delaware C-Corp completion, finalized cap table, final IP assignment chain, or finalized SAFE terms until counsel/CFO confirms.
- Every proof claim must keep its evidence label, artifact, context, and caveat.
