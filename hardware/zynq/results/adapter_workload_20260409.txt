ATOMiK Multi-Buffer Change Detection Workload
==============================================

Environment: VexRiscv SMP @ 100 MHz, 4 KB D-cache, no L2
Timer: rdtime @ 100 MHz (10 ns resolution)
Note: memcmp degrades above 4 KB due to cache thrashing

[CSR (direct)] ATOMiK v2, 1 bank(s) @ 0xF0000000

32x1024B 10%chg      |     679582 cy |       9200 cy |     73.9x |     347826

=== DEMO STATE MONITOR (ADAPTER) ===
/root/demo_state_monitor 0xF0020000 adapter
ATOMiK State Change Monitor
===========================

Model: track one region, detect changes at each tick.
Writes accumulate deltas at write time (O(1) per write).
Detection: software rescans all bytes; ATOMiK reads one flag.

ATOMiK v2 @ 0xF0020000 (adapter) | VexRiscv SMP 100 MHz

Scenario           │ SW (memcmp)  │ ATOMiK       │ Speedup  │ Correct
───────────────────┼──────────────┼──────────────┼──────────┼────────
256B, 1 write      │      64346 cy │      25951 cy │    2.5x │ YES
1KB, 1 write       │      30135 cy │      64196 cy │    0.5x │ YES
4KB, 1 write       │      83982 cy │      26995 cy │    3.1x │ YES
16KB, 1 write      │     179484 cy │      27765 cy │    6.5x │ YES
64KB, 1 write      │      48206 cy │      64980 cy │    0.7x │ YES
4KB, no change     │     946911 cy │      65317 cy │   14.5x │ YES
64KB, no change    │   13888441 cy │      28644 cy │  484.9x │ YES

Key: software cost grows with region size.
     ATOMiK cost is constant (~260 cycles) regardless of size.
     Deltas accumulate at write time, not at detection time.
