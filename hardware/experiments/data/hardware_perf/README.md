# Hardware Performance Data

Append-only data pool for ATOMiK PicoRV32 SoC performance benchmarks.

## Files

| File | Purpose |
|------|---------|
| `perf_pool.jsonl` | Append-only pool (one JSON object per line per run) |
| `runs/` | Per-run JSON snapshots with full data |

## JSONL Schema

Each line in `perf_pool.jsonl` is a complete JSON object:

## Benchmark Keys

### ATOMiK Core Ops
- `atomik_load` - Write LOAD register latency
- `atomik_accum` - Write ACCUM register latency
- `atomik_read` - Read STATE register latency
- `atomik_roundtrip` - Load + accumulate + read combined
- `mmio_write` - Raw MMIO write (bus + CDC overhead)
- `mmio_read` - Raw MMIO read

### Memory Operations (keyed by `<test>_<size>`)
- `memcpy_sw_<N>` - Software memcpy at N bytes
- `memcpy_atomik_<N>` - ATOMiK tracked memcpy at N bytes
- `memset_sw_<N>` - Software memset at N bytes
- `memset_atomik_<N>` - ATOMiK verified memset at N bytes
- `fingerprint_<N>` - XOR fingerprint at N bytes
- `change_detect_<N>` - ATOMiK change detection at N bytes
- `memcmp_sw_<N>` - Software memcmp at N bytes

Sizes: 32, 64, 128, 256 bytes

### Burst & Scaling (keyed by `<test>_<count>`)
- `burst_accum_<N>` - N sequential accumulates
- `checkpoint_create_<N>` - Fingerprint creation for N words
- `checkpoint_verify_<N>` - Fingerprint verification for N words

### CPU Baselines (keyed by `<test>_1000`)
- `loop_overhead_1000` - Empty loop, 1000 iterations
- `func_call_1000` - Trivial noinline function calls, 1000 iterations
- `xor_bench_1000` - XOR shift benchmark, 1000 iterations

## Usage

```bash
# Run benchmarks
python hardware/scripts/perf_runner.py --port /dev/ttyUSB1

# Load data in Python
import json
with open("perf_pool.jsonl") as f:
    runs = [json.loads(line) for line in f if line.strip()]
```

## Collecting

Generated by `hardware/scripts/perf_runner.py` which:
1. Sends 'R' command to firmware via UART
2. Captures `##PERF:` tagged lines
3. Computes statistics (mean, median, stdev, percentiles)
4. Removes outliers (modified Z-score > 3.5)
5. Appends to pool and saves snapshot
6. Compares to previous run (flags >5% regressions)
