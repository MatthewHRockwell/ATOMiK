unless an end-to-end artifact proves a source file, compile command, output
artifact, target runtime, and recorded output.

## Adoption Staircase

1. Explore the primitive in software.
2. Test it against a real workload.
3. Move into hardware-backed evaluation.
4. Assess integration into broader architecture.

## Artifact Requirements

To upgrade a compiler-adoption claim from `ROADMAP` to `HARDWARE_VALIDATED`,
publish:

- source file
- compile command
- output artifact
- target board or runtime
- recorded output
- date and commit hash
- evidence label

Until then, keep the compiler lane framed as product direction.
